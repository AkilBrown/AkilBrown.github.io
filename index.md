# Sanom Shorts Uploader

Sanom Shorts Uploader is a private tool for the owner of the Sanom Shorts YouTube channel. It uses MoneyPrinterTurbo to render short videos and GitHub Actions to run the workflow. With the channel owner’s Google authorization, it verifies the connected channel, uploads videos, and reads video performance to improve future episodes.
