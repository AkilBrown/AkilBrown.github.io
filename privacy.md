# Privacy Policy

Sanom Shorts Uploader uses YouTube API Services. With the channel owner’s permission, it accesses the authorized channel’s identity, uploads videos, and reads video-level performance data to guide future production. It uses this information to operate the Sanom Shorts workflow.

Google authorization credentials are stored in private GitHub Actions secrets. Channel IDs, uploaded video IDs, and performance records used by the workflow are stored privately. The workflow does not send YouTube authorization credentials or private YouTube analytics to the script-generation service.

You can revoke access through [Google Account permissions](https://security.google.com/settings/security/permissions). To request deletion of stored YouTube API data or ask a privacy question, contact sanom5371@gmail.com. See also the [Google Privacy Policy](https://policies.google.com/privacy).
